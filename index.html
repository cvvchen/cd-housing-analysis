⚠ 买之前必须搞清的4件事
  • 小学划片 ≠ 直升初中。大源片区是「多校划片」：蒙彼利埃、益州、锦晖天府、墨池书院、霍森斯这5所单设小学的毕业生， 统一填报志愿、摇号进入3所初中（教科院附属学校 / 石室天府锦城湖 / 教科院附中天府五街）。 锦晖天府小学同样走摇号，不是直升——很多中介会说错这一点。
  • 真正能"直升"的只有2所九义校小学：教科院附属学校小学部、高新中学天府一街分校（原大源学校）。 买这两所的对口小区，初中确定性最高。
  • 2026年起实行"双一致"优先：需「人户一致 + 父母100%产权（不能与祖辈共有）」才能稳拿大源片区摇号资格； 教科院附属学校的直升还要求户口与房产证完全一致——2026年4月已有在读六年的家长因房户不一致被取消直升。 且2026年起「同区不同片选学籍将被统筹」，只有学籍没户籍不再能直升。光有房不够。
  • 公园小学2026年没有毕业生（2021年开办，首届2027年），今年小升初不适用； 但买房是长期决策，它属大源片区多校划片，2027年起正常参与。

六、选房建议

0. 先给结论：你的钱该怎么花

  1. 300万预算 + 必须3室 + 大源学区，这个组合的现实答案是：能买，但只能买「大源片区里房龄偏老、或单价偏低的次新」，指望蒙小/霍森斯这种顶流小学的核心次新3室，300万基本进不去。
  2. 决策顺序建议改成这样：先锁「初中确定性」→ 再锁「小学质量」→ 最后在总价带里挑房子。因为初中是6年后的事、小学是眼前的事，而这两者的确定性结构完全不同（小学看划片，初中看摇号）。
  3. 如果你把「初中确定性」放在第一位：唯一的路径是买教科院附属学校小学部 / 高新中学天府一街分校这两所九义校的对口小区（保利心语系、逸都国际、仁美大源印象、合能璞丽、欢乐颂、高投天悦锦萃、天府锦上锦花园等），但要接受两点：① 2026年起要「人户一致+100%产权」；② 这些小区不再参加大源三校摇号，等于放弃了石室天府锦城湖和教科院附中。
  4. 如果你把「小学质量+摇号机会」放在第一位：就在蒙小/霍森斯/益州/墨池书院/锦晖天府这5所里选，然后接受初中是摇号——但好消息是，大源那3所初中没有弱校，摇中任何一所都不亏。

1. 学区风险：三个中介最爱隐瞒的坑

  1. 坑一：把「锦晖天府小学」说成能直升教科院附校。它是单设小学，走大源片区多校划片摇号，不是直升。真正能直升的是教科院附属学校小学部（四街）和高新中学天府一街分校（原大源学校）。
  2. 坑二：把「锦晖小学」和「锦晖天府小学」混为一谈。这是两所完全不同的学校，锦晖小学在站南片区，对口的是七中初中天环/锦城、石室天府交子，跟大源这3所初中毫无关系。签约前一定核对合同/查档上的准确校名。
  3. 坑三：2026年起大源实行「双一致」（人户一致+100%产权）优先。以前那种「买个小户型挂户口、人在别处住」的做法，从2026年起拿不到片区摇号的保障。而且教科院附属学校的直升明确要求户口与房产证完全一致——2026年4月已有在读六年的孩子因房户不一致被取消直升。买房时务必让产权人和落户人一致。
  4. 补充：公园小学2026年没有毕业生（2021年开办，首届2027年）。这一年买它的学区房，小学能读，但初中还没到需要决策的时候，不影响购买，但别信「公园小学直升某某初中」的说法。

2. 价格与户型：300万3室怎么挑才不亏

  1. 优先盯「70-90㎡的紧凑3室」而不是「110-130㎡的舒适3室」。同样的总价，小面积3室=更高单价的小区+更好的学区；大面积3室=更老的房子或更边缘的位置。学区房的溢价主要买在学票上，不是买在面积上。
  2. 大源片区3室的主流面积段是85-130㎡。300万预算下，85-100㎡是主战场；如果看到120㎡以上还能压进300万，大概率是房龄15年以上、无电梯、朝向差或临街，要单独核验。
  3. 看成交价、不看挂牌价。本报告第四节的成交数据是真实网签价，能直接反映议价空间。注意成交卡片上的「较挂牌降X万」标签——大源片区近两年平均议价空间普遍在5-10%，个别房源能谈到10%以上，这是你的谈判弹药。
  4. 成交周期是反向指标：挂牌超过300天才成交的房子，说明定价偏高或房子有硬伤，这类房源反而是最好的压价对象；7天内成交的，说明定价合理甚至偏低，你没什么议价空间，看到合适的要快。
  5. 警惕「满五年/满两年」标签。不满五年的房子有增值税和个人所得税，300万的房子税费差可能到10-20万。如果你是按「总价不能超300万」的硬约束，务必把税费算进去单独看，或者直接只筛满五唯一。

3. 谈判与交易：什么时候出手、怎么压价

  1. 出手时机：大源片区每年有两次明显的成交高峰——「3-5月幼升小报名前」和「8-9月开学后」。前者是卖方市场，价格最硬；后者（尤其11月到次年1月）是买方市场，谈价空间明显更大。如果你不急着赶明年入学，建议在冬季谈。
  2. 压价三件套：① 拿同小区近3个月的成交价去谈（本报告可直接引用）；② 用「房户一致/满五唯一」这些手续问题要求折价；③ 用一次性付款或高比例首付换折扣，通常能再谈1-3%。
  3. 必须现场核验的5件事：① 学位是否被占用（去学校或教育局查，这是学区房最大的雷，占了学位的房子等于买了个普通房）；② 是否满五唯一；③ 产权是否有抵押/共有纠纷；④ 房龄与贷款年限（房龄超过20年，很多银行只能贷到「房龄+贷款年限≤50年」，月供压力会变大）；⑤ 小区是否在当年划片范围内（拿门牌号对照，不要拿小区名对照）。
  4. 贷款提醒：学区房总价高、房龄偏老，建议先做贷前预审再谈价。300万的房子，首付三成是90万，但如果房龄老、评估价低于成交价，实际首付可能要到100-110万，提前留出余量。

4. 我的排序建议（按你的两个约束）

  1. 第一优先：教科院附属学校小学部对口小区（保利心语系等）——初中确定性最高（直升），但要接受「双一致」门槛，且3室房源稀缺、总价往往顶到300万上限。适合「孩子马上要上小学、最怕摇号不确定」的家庭。
  2. 第二优先：墨池书院小学 / 益州小学 对口小区——这两个片区3室房源供给最充足（因为小区体量大、房龄跨度大），300万内可选面最广，纯从「买得到」的角度最优。初中走摇号但三校无弱校。
  3. 第三优先：蒙彼利埃小学 / 霍森斯小学 对口小区——学区口碑最强，但核心次新3室普遍超过300万，300万内基本只能买到老小区或小面积，属于「用居住品质换学票」。适合「学区优先、可接受老房子」的家庭。
  4. 第四优先：高新区公园小学 对口小区——目前性价比不错、摇号资格与上述一致，但2026年没有毕业生，短期政策信息最少，属于「赌未来」的选择。
  5. 最后一句实话：300万在大源买3室学区房，本质是在「学区质量、房龄、面积」三者之间做取舍，不可能全占。建议你先把上面5件事（学位、满五唯一、产权、房龄、划片核验）当成筛选条件过一遍，剩下的再谈价值和喜好。
