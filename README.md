**筛选条件**：成都高新区 · 成交总价 ≤ 300万 · 必须3室 · 限6所目标小学 + 3所目标初中

1. **6所目标小学**的官方划片范围（含2026年官方门牌号）与对应小区

6. 房产销售视角的选房建议

## 重要提示

- **学区划片**以成都高新区2026年官方划片公告为准（门牌号口径）；小区名与门牌的映射来自公开渠道整理，**购房前请以官方文件与产调结果复核**。
- **行情数据**为2026年10月挂牌价与房东估价，**不是成交价**；真实成交通常低于挂牌价5–10%。
- 本页面仅供选房决策参考，**不构成交易依据**。
